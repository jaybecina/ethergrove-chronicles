# Ethergrove Chronicles: Name, Story and RPG Design Spec

**Status:** draft for review · **Date:** 2026-10-29 · **Author:** Jay Becina (with Claude) · **Builds on:** Part 1
and the tutorial (merged to `main`) · **Replaces:** Part 1 spec Appendix A (the old story bible) and its roadmap

This spec does two jobs:

1. **The rename (§3)** is built right after this spec, on branch `feat/ethergrove-chronicles`. It is exact:
   every name, key and line of text is given. Where it says "MUST", do exactly that.
2. **The story bible and RPG design (§4–§8)** are the design target for later parts. Each later part gets
   its own spec and plan, which may tune the draft numbers marked **(draft)** but not the story, names or
   rules.

---

## 1. Goal

The game today is Hearthvale, a cozy farm loop with a story bible that follows Harvest Moon too closely: a
dead grandpa's farm, small helper spirits, a company buying the town, a three-year deadline, and festivals
named like the genre's classics. The owner wants:

- an **original name** that is not already a game: **Ethergrove Chronicles**;
- an **original story** of our own, mixed with a real RPG: **XP levels, dungeons, bosses, mining, magic
  crops and fantasy creatures**;
- **real-time combat in the style of Outward** (stamina, lock-on, dodge, block, parry), **not turn-based**;
- the **Harvest Moon life-sim loop** kept as the heart of the game (farm, seasons, town, friendship,
  romance);
- **no town building** (no sim-style construction);
- a **2.5D look**: fixed camera, baked places and backgrounds, 3D characters and monsters, so the game stays
  smooth on phones.

### 1.1 Success criteria

1. After the rename, no player-facing text, page title, package name or storage key says "Hearthvale",
   except the legacy keys the save carry-over reads (§3.4).
2. Players with Hearthvale saves and settings keep them after the rename, with no action on their part.
3. A reader of §4 can name what is original in the story and what is a shared genre mechanic (§4.9).
4. Every later part can be specced from §4–§8 without asking the owner the story, names or rules again.

### 1.2 Decisions already made (do not revisit)

| Decision | Choice |
|---|---|
| Name | **Ethergrove Chronicles** (short form **Ethergrove**). The valley is also called Ethergrove. |
| Story base | **The Rootwake** (§4), with Grandpa **missing, not dead** |
| Progression | **XP levels 1–50** plus three skill trees |
| Combat | **Real time, Outward-style** (§6.3). Never turn-based. |
| Look | **2.5D:** fixed camera, baked backdrops, 3D characters, monsters and things that change (§7) |
| Town | A town of villagers and shops (**Lowmere**). **No town building.** |
| Audio | **Out of scope.** No music, sound effect or BGM work until its own part (§9). |
| Where the rename is built | Branch `feat/ethergrove-chronicles`, in its own worktree cut from `main`. The uncommitted orchestral-audio work on `feat/bgm-sound-effects` is not touched. |

### 3.4 Carry-over of saves and settings

**Settings.** `loadSettings()` reads `ethergrove:settings`. If that key is missing and
`hearthvale:settings` exists, it parses the old value the same way, writes it to `ethergrove:settings`,
then removes `hearthvale:settings`. Invalid old JSON falls back to defaults (as today) and the old key is
still removed.

**Saves.** A new function `importLegacySaves(db)` in `apps/web/src/save/legacyImport.ts` runs once, inside
`createIdbRepository`, before the first read of the `ethergrove` database:

1. If the `saves` store has the key `meta:legacyImport`, stop.
2. Open the legacy database `hearthvale` (version 1). If opening it would create it (the `upgrade`
   callback runs with `oldVersion === 0`), abort that upgrade transaction so no empty `hearthvale`
   database is left behind, and treat it as "no legacy saves".
3. For each key `slot:1`, `slot:2`, `slot:3` and their `:backup` keys: if the legacy value exists **and**
   the new store has no value for that key, copy it unchanged. (Saves still go through `migrate()` on load,
   as today.)
4. Write `meta:legacyImport` with the value `{ from: 'hearthvale', at: <ISO date string> }`, whether or
   not anything was copied, and close the legacy database.
5. Never delete or change the legacy `hearthvale` database. A later release may remove it.
6. Any error in steps 2–3 is caught: write the marker anyway so the game never retries forever, and log
   `console.warn('Ethergrove: could not import Hearthvale saves', error)`.

`list()` reads only the slot keys, so the marker key never shows as a slot.

**Save files.** Import already accepts any `.json`, so old `.hearthvale.json` files keep working. A test
pins that.

## 4. Story bible

### 4.1 Logline

You take over your missing grandpa's farm in the valley of Ethergrove, and learn the farm is the lid on the
deepest ruin in the world.

### 4.2 The world

| Term | Meaning |
|---|---|
| **Ethergrove** | The valley, and the name of the buried forest's living magic |
| **The Undergrove** | A forest of crystal trees buried under the valley. Its roots carry **ether** through the soil. |
| **Ether** | The magic in the roots: it makes things grow, powers spells, and glows in magic crops |
| **The Veyl** | An ancient people who "sang" the roots to force endless harvests. They drew too much; their cities sank. |
| **The Deeps** | The Veyl's sunken cities, now dungeons with floors, ore, monsters and a boss each |
| **The Gloam** | Overdrawn ether that has turned sour. It leaks up from the Deeps, twists animals into **Gloamed** beasts and sours fields. |
| **Rootwarden** | A keeper who tends the roots and holds the Gloam back. Grandpa Elias is the last one. |
| **Rootstones** | Five stones that steady the roots. Each Deep's boss guards one; returned to the **Root Shrine** on the farm, it wakes a branch of the Undergrove. |
| **Lowmere** | The valley's town: shops, clinic, forge, pier, villagers |
| **The Lantern Guild** | A delvers' order that hunts raw ether in the Deeps. Their reckless digging feeds the Gloam. |

### 4.3 Premise

- **The player** (named by the player, any gender) receives Grandpa Elias's letter (§3.3) and arrives at an
  overgrown farm. Part 1 and the tutorial stay as they are.
- **Grandpa is missing.** A year ago he walked into the Heartdeep under the farm's root cellar and never
  came back. Lowmere thinks he is dead. Granny Fern, his old friend, does not.
- **The Gloam is rising.** Storms leave sour patches on fields; Gloamed beasts wander the woods at night.
- **The main question:** what happened to Grandpa, and what is he holding back down there?

### 4.4 The twist (revealed by Grandpa's journal pages)

Twelve torn pages are found across the game: two in each Deep (ten), one at Lantern Drift (§4.7) and one in
Granny Fern's 6-heart event. Read in order they reveal:

1. The Gloam isn't a monster. It is the **nightmare of Isel**, the last Veyl Rootsinger, asleep in the
   roots since her city sank.
2. Rootwardens never sealed a monster: they kept Isel asleep and her nightmare small.
3. Grandpa went down because the Lantern Guild's digging was waking her too fast, and her nightmare had
   taken a shape: the **Hollow Warden**.
4. Victor Hale, Grandpa's son, joined the Lantern Guild to find his father, and believes Elias always chose
   the valley over him.

### 4.5 Story chapters

| Ch. | Deep | Story beat | Rootstone |
|---|---|---|---|
| 1 | Mossdeep | Find Grandpa's lantern on the last floor. Meet the Lantern Guild and Victor. | Verdant |
| 2 | Cinder Galleries | Help Hilda reforge Grandpa's Rootwarden blade. Victor races you to the boss. | Ember |
| 3 | Drowned Archive | Read the Veyl archive: learn Isel's name. Victor is hurt by the Tidewyrm; you can carry him out. | Tide |
| 4 | Frostvault | Find Grandpa's last camp and the last page he wrote. The way to the Heartdeep opens. | Rime |
| 5 | Heartdeep | Fight the Hollow Warden, wearing the Gloam's copy of Grandpa's armour. Find Grandpa alive, holding the nightmare back. Meet Isel. | Heart |

If the player carried Victor out in Chapter 3, he fights beside them in the Chapter 5 boss and reconciles
with Elias in the ending.

### 4.6 Endings (the game continues after both)

- **Wake Isel:** the Undergrove fully wakes; magic crops grow in every season; the Gloam fades; Isel comes
  to live in Lowmere as a villager.
- **Bind Isel:** Isel sleeps for another generation, her nightmare sealed; the player becomes the new
  Rootwarden; Grandpa retires to the farm.
- Each ending adds an epilogue for the spouse (if married), Victor, and each romance candidate.

### 4.7 Cast

**Romance candidates** (any player may marry any of them):

| Name | Role | Tie to the story | Arc in one line |
|---|---|---|---|
| Mira | herbalist, clinic apprentice | brews tonics from magic crops | Learns to trust her own remedies over old books |
| Theo | blacksmith's son | forges gear from Deep ore (Ch. 2) | Wants to leave the valley; finds a reason to stay |
| June | fisher who runs the old pier | guides you to the Drowned Archive (Ch. 3) | Fights to save the pier her mother built |
| Rowan | tracker who hunts Gloamed beasts | scouts the Frostvault (Ch. 4) | Lets people back in after losing his partner to the Gloam |
| Celeste | Lantern Guild cartographer | maps the Deeps for Victor | Torn between the guild and the town she starts to love |
| Sol | traveling merchant (the Part 1 cart) | carries old Veyl songs; helps read the journal | A wanderer who has never had a home |

**Townsfolk:** Mayor Bram (worried, kind), Granny Fern (Rootwarden lore, Grandpa's old friend), Hilda
(blacksmith, Theo's mother), Doc Aldous (clinic; where you wake after falling in a Deep), Pip and Wren
(kids who believe in Kindlings), Old Marlow (retired fisherman), Victor Hale (Lantern Guild captain, your
uncle).

**Kindlings** are ether wisps that wake as the roots heal (one per Rootstone). They **fight beside you in
the Deeps** (light, a small heal, revealing hidden doors) and grow stronger when fed magic crops. They do
no farm chores. Part 1's Kindling glimpse on the first harvest stays.

**Romance flow:** gifts and daily talks build hearts (0–10); heart events at 2 / 4 / 6 / 8 / 10. At 10
hearts, propose with a **Lumen ring** forged at Hilda's after Chapter 1. The wedding is at the Root Shrine.
The spouse moves in and, once a day, can **join you in a Deep** as a companion. No children (out of scope).

### 4.9 Originality check

| Kept: shared genre mechanics (not ownable) | Removed: too close to Harvest Moon, Stardew Valley or Rune Factory |
|---|---|
| Seasons, crops, farm tools, energy, shipping, sleep to save | Grandpa **dead**, leaving the farm in a letter |
| A town, friendship hearts, heart events, marriage | Small spirits that do farm chores |
| Festivals as an idea | A company buying the town; a relative as a corporate CEO |
| Dungeons with floors and ore | A fixed deadline (three years) to save the town |
| | Festivals named like the classics (Flower Dance, Star Night, Harvest Fair) |
| | Rune Factory signatures: amnesiac hero, monster taming, a town built around a dragon |

## 5. Gameplay loop

- **A day:** farm in the morning, Lowmere in the afternoon, a Deep in the evening, sleep to save. The farm
  loop from Part 1 is unchanged.
- **Everything grows you:** fighting, mining and farming all give XP (§6.1).
- **Two bars, two jobs:** the existing **Energy** pays for farm tools and mining swings and refills when you
  sleep. **Stamina** (§6.3) pays for combat moves and refills in seconds.

### 5.1 Magic crops (draft)

Seeds are found in the Deeps; Sol sells each kind after its chapter. Magic crops follow the Part 1 crop
rules (watering, seasons) and **clear Gloamed soil** on the tile they grow on.

| Crop | Seasons | Days to grow | Regrows | Use |
|---|---|---|---|---|
| Lumenroot | spring | 5 | no | Lumen tonic: reveals hidden doors in Deeps for 5 min |
| Moonwheat | spring, summer | 7 | no | Moonflour: restores Ether |
| Emberkin squash | summer | 9 | no | Ember oil: adds fire damage to a weapon for one delve |
| Galeberry | summer, fall | 6 | every 3 days | Faster Stamina refill for 5 min |
| Heartvine | fall | 10 | every 4 days | Healing salve; favourite Kindling food |
| Frostlace | winter | 8 | no | The only crop that grows in winter; frost resistance |

### 5.2 The Deeps (draft numbers)

Each Deep opens once and stays open. Floors have checkpoints every 4 floors (an elevator stone).

| # | Deep | Entrance | Floors | Levels | Ore | Boss | Opens when |
|---|---|---|---|---|---|---|---|
| 1 | Mossdeep | the old well in the Lowmere woods | 8 | 1–10 | Copper | Bramble Matron | Spring Y1 day 8, or the first shipment, whichever comes later |
| 2 | Cinder Galleries | the quarry mine | 10 | 10–20 | Iron | Slag Colossus | Summer Y1 day 1, Mossdeep cleared |
| 3 | Drowned Archive | the lake bed at the old pier | 10 | 20–30 | Ethersteel | Tidewyrm | Fall Y1 day 1, Cinder Galleries cleared |
| 4 | Frostvault | the north pass | 10 | 30–40 | Rimesilver | Rime Stag | Winter Y1 day 1, Drowned Archive cleared |
| 5 | Heartdeep | the farm's root cellar | 12 | 40–50 | Heartglass | Hollow Warden | Spring Y2 day 1, four Rootstones returned |

### 5.3 Bosses

| Boss | Arena idea | What it teaches |
|---|---|---|
| Bramble Matron | Thorn walls split the arena; phase 2 summons saplings | Reading telegraphs, using Ember oil |
| Slag Colossus | Heavy slams leave molten pools; strike its glowing seams | Positioning, heavy attacks |
| Tidewyrm | Dives into water channels; the arena floods in phase 2 | Lock-on switching, ranged attacks |
| Rime Stag | Fast antler charges, ice spikes | Parry: a parried charge staggers it |
| Hollow Warden | The Gloam in Grandpa's armour, using his own Rootwarden moves; three phases | Everything; Kindlings and companions matter |

## 6. RPG systems (draft values)

### 6.1 Levels and XP

- Levels **1–50**. XP needed to go from level L to L+1: `round(100 × L^1.5)` (L=1: 100; L=10: 3,162;
  L=49: 34,300).
- **XP sources:** a monster gives `10 × its level`; a boss gives `1,000 × Deep number`; a first-time
  discovery (new floor, new journal page, new magic crop shipped) gives 50; each harvest gives 1 per crop,
  and 5 per magic crop.
- **Each level:** +8 max HP, +3 max Stamina, +2 max Ether, +1 skill point. **Level 1:** 100 HP, 100 Stamina,
  30 Ether.

### 6.2 Skill trees

Three trees, each skill with ranks 1–3 (one point per rank). The combat spec gives exact effects.

| Blade (weapon arts) | Warden (defence) | Ether (magic) |
|---|---|---|
| Riposte, Cleave, Lunge, Whirl | Shield Bash, Iron Stance, Second Wind, Root Guard | Ember Bolt, Frost Ward, Lumen Flash, Rootgrasp |

### 6.3 Combat (Outward-style, real time)

- **Moves:** light attack, heavy attack (hold), dodge roll, block, parry (block at the right moment), one
  equipped skill per slot (2 slots, 4 at level 25).
- **Stamina costs:** light 12, heavy 25, dodge 20, running inside a Deep 10 per second (running on the farm
  and in town is unchanged from Part 1). Blocking drains stamina by half the
  damage blocked. Stamina refills at 30 per second after 0.8 s without spending.
- **Dodge:** 0.25 s with no damage taken. **Parry window:** 0.15 s; a parry staggers most enemies.
- **Lock-on:** the nearest enemy in a 10 m cone in front; switch target with one input.
- **Enemies telegraph** every attack for at least 0.5 s (a glow or wind-up), and bosses for at least 0.7 s,
  so phone players can react.
- **Weapons:** sword, spear, staff, bow, and a two-handed greataxe (the farm axe is a tool, not a weapon).
  **Gear slots:** weapon, off-hand (shield or focus), head, body, feet, two trinkets. **No durability.**
- **Falling in a Deep:** you wake at Doc Aldous's clinic at 20:00 the same day (or 08:00 the next day if it
  was already past 20:00) and lose **half of the loot picked up on this delve**. Gold and equipped gear are
  never lost.
- **Controls:** every move works on keyboard, gamepad and touch. Touch uses auto lock-on and four large
  buttons (attack, dodge, block, skill), each at least 44 × 44 px. The combat spec gives exact bindings.

### 6.4 Mining

- A **pickaxe** joins the tool belt. Ore nodes appear in the Deeps. A swing costs 4 Energy (like the
  hammer); copper nodes take 2 hits and each later ore one more.
- Hilda's forge turns ore into bars and gear. Theo unlocks the higher tiers.

### 6.5 Playtime targets

One in-game day is about 12.6 real minutes if played to midnight; players average 8–10. A year is about
15–19 hours.

| Player | Target hours | Finishes |
|---|---|---|
| Rushing the story | 20–25 | Five Deeps and an ending |
| Typical | 30–40 | Story, a good farm, a few friendships, around level 30–35 |
| Completionist | 70–90 | Every journal page and crop, level 50, all skills, all heart events, both endings |

## 7. Visual direction: 2.5D places, 3D characters

This is the target for the renderer part (Part 3). It starts only after the frame-rate profile (§7.3)
measures the current costs. Updated 2026-10-31 after a baked proof of the farm
([[decisions/0013-baked-backdrops-in-the-browser]]).

### 7.1 Two renderers: one for play, one for baking

- **Gameplay renderer:** three.js `WebGLRenderer` through React Three Fiber, as today. Players never run a path
  tracer.
- **Bake tool (dev only):** `three-gpu-pathtracer`'s `WebGPUPathTracer` renders the backdrops offline. It works
  like the audio studio: a dev-only page that Playwright drives, writing image files that are committed. The
  package is a dev dependency only and must not appear in the production bundle.
- **Bake tool rules (verified 2026-10-31 on an Apple M4):**
  - Use `WebGPUPathTracer`, never the deprecated `WebGLPathTracer`. Its shader fails validation on ANGLE Metal
    and every WebGL context on the page is lost.
  - Drive it with Playwright's full Chromium (`chromium.launch({ channel: 'chromium' })`), not the default
    headless shell, where GPU readbacks hang.
  - Submit one `renderSample()` per timer tick. Queuing many in a loop floods the GPU and freezes the page.
  - Cost: 256 samples at 960 × 540 take about 40 s per frame on the M4.

### 7.2 The look

- **Camera:** a fixed angle, the current 50° pitch (`CAMERA_PITCH_DEG`) with one fixed yaw. It follows the player
  by panning only. The Q/E rotation, the three zoom steps and their tests are removed in that part.
- **Projection: orthographic (draft).** The camera pans to follow the player, and a baked image stays correct
  under a panning camera only when the projection is orthographic: panning then moves the image by a plain 2D
  shift. With perspective, a backdrop is only right from the spot it was baked at. The renderer spec confirms
  this with an orthographic proof bake, because the 2026-10-31 proof frames were rendered in perspective and
  the look changes slightly.
- **Baked places:** static scenery (cliffs, buildings, distant trees, dungeon walls) is baked into backdrop
  images from the CC0 3D packs already credited. Each area has, per season, a **colour image and a depth
  image**, so 3D characters pass behind pillars and trees correctly. Orthographic depth is linear; the
  renderer spec sets its precision and the image tiling.
- **Always 3D:** player, villagers, monsters, bosses, Kindlings, crops, farm tiles, ore nodes, chests,
  anything that moves or changes. Repeated live objects (crops, soil tiles, fence posts, ore nodes) stay
  instanced, as today (`InstancedSet`, `ModelInstances`).
- **Light:** baked into the backdrops, with a colour tint for time of day; blob shadows under characters. No
  screen-space ambient occlusion. If the renderer keeps a real-time shadow map as a fallback, only live
  objects cast into it, and it re-renders only when they change (`shadowMap.autoUpdate = false`, then
  `shadowMap.needsUpdate = true`), never every frame.
- **Resolution:** the device pixel ratio stays capped per quality tier (today High 2, Low 1.5). The profile
  sets the 2.5D values.
- **Targets (draft):** 60 fps on desktop; at least 45 fps (aiming for 60) on the mid-range phone profile;
  at most 100 draw calls in a farm view.

### 7.3 Frame-rate profile (before the renderer part)

- **What it measures:** today's renderer on the farm, from the same camera, at the High tier, and then with one
  cost removed at a time: device pixel ratio capped at 1, the N8AO pass off, the shadow map off, grass off,
  particles off.
- **Numbers per run:** CPU frame time (median and 95th percentile), GPU frame time where the browser exposes
  `EXT_disjoint_timer_query_webgl2`, and draw calls and triangles from `renderer.info`.
- **Where it runs:** desktop Chromium on a real GPU, and a phone stand-in (Pixel 7 viewport with 4× CPU
  throttling). Never SwiftShader, which measures software rendering. The phone stand-in is an estimate until
  the game is checked on a real mid-range phone.
- **Output:** a report in `docs/perf/`. Not a CI gate.

### 7.4 Considered and not adopted

- **The path tracer as the gameplay renderer:** it converges over seconds, so it can't run per frame.
- **A photo mode using the path tracer:** possible later; not part of the renderer part.
- **Benchmarking against "a standard `WebGLRenderer` mode":** the game already uses `WebGLRenderer`. The
  profile (§7.3) measures what each cost adds instead.
- **Level of detail and billboards for distant scenery:** distant scenery is baked, so nothing far away is
  drawn live.
- **Switching to Godot:** its web export is about 5–9 MB before content (the game's JavaScript is about 580 KB
  gzipped), it is limited to WebGL 2 in the browser, and the game, saves and tests would be rewritten.
- **Blender, or AI-generated backdrops:** the in-browser bake uses the game's own models and camera, so
  Blender adds a tool without adding quality. AI images have no matching depth image and break the CC0-only
  rule ([[decisions/0004-original-ip-cc0-only]]).

## 8. Out of scope

- **Music, sound effects and BGM** until their own part (§9). Nothing in this spec designs audio.
- Town building, monster taming, children.
- Implementing combat, the Deeps, magic crops or the 2.5D renderer in this branch: each gets its own spec.
